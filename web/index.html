      设置

      配置 LLM 与文档解析器

      LLM 配置

      密钥默认仅保存在当前浏览器会话；只有发起模型请求时才发送到你配置的 API 地址。

      多模态检索会通过知识图谱记录文本中对「图N / 表N」的引用位置，命中文本时自动附带关联的图片与表格（图片交由 VLM 理解）。

      VLM 配置（多模态检索）

      视觉语言模型用于理解文档中的图片/表格。未配置时，多模态检索仍会返回图片/表格引用，但不会生成图片描述。密钥仅保存在本浏览器。

      解析器插件

      选择 PDF 的解析方式。插件式架构，可扩展更多解析器。

      前往 mineru.net 获取 API Key。PDF 将发送到 MinerU 官方 API 解析。

      注意：启用 MinerU 后，上传的 PDF 会发送到对应 MinerU 服务解析。请仅使用你信任的服务。

      记忆设置

      对话记忆与长期记忆均只保存在本浏览器，可随时清除。

      开启后，提问会带上最近若干轮对话上下文（第 1 层短期记忆）。

      每轮 = 一问一答。值越大模型越能"记得前文"，但 token 消耗越高。
